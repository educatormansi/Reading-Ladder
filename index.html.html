How to use this app

1. Check the rosterOpen Students. Your existing students are already loaded. If any are missing, use Import students to paste or upload the rest — duplicates and bad values are flagged automatically, nothing else is touched.
2. Log weekly progressOpen Weekly Progress, click Log weekly progress, search the student's name, pick the week and current level. Saving again for the same student + week edits that record instead of duplicating it.
3. Enter the endlineWhen the intervention cycle ends, open a student's profile from the Students table and set their Endline Reading Level. Growth and Goal Status calculate themselves.
4. Read the dashboardsAnalysis is read‑only and always current — school-wide numbers, charts, and a grade‑by‑grade table. Nothing there is typed in by hand.
5. Adjust the framework if neededReading Framework holds the goals, groups and priorities every calculation is based on. Edit a cell and every student and dashboard updates immediately.
6. Find a student fastIn Students, search by name or filter by grade/group, then click any row to open their full profile and weekly history.
